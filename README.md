## Commands

### Print Bakery

`print:bakery <name> <flag> <[ingredients]>` 

Prints a bakery to the terminal. The ingredients list is split into groups of 5, if the group contains correct ingredients a cake emoji is added to the bakery window, otherwise a poop emoji is added.

`--test` - Will print the string of produce.


### Check version

`php artisan check:version`

Checks the development environment versions meet the projects required versions set in  `projectRequirements.json`
