# Calculator project

This is a throw away project to get comfortable with Laravel

## Parts

### Commands

`print:bakery <name> <flag> <[ingredients]>` Will split the ingredients array into groups of 5 and attempt to bake cakes.
Successful cake baking will result in a cake emoji, unsuccessful baking will result in the poop emoji.

The produce of the bakery will be printed to the terminal.

`-T` - Will print the baked goods as a single string for testing purposes
